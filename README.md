Push-optimal Sokoban solver for the make.fun bounty [sokoban-solver-01-run-20261121](https://make.fun/bounty/sokoban-solver-01-run-20261121): room-by-room push BFS with deadlock pruning (dead squares, frozen 2x2 blocks), A* fallback for levels that are no set of rooms. Deterministic; budgets by work (state counts), never by the clock. Practice set: all 5 instances solved at the optimal push counts, score 1,000,000, ~1.5 s of the 60 s wall.
